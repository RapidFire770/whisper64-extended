# BAS to SEQ Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a desktop program that reads a VS64 `.bas` file and writes a CR-terminated SEQ the Whisper64 editor can open, with labels left for `W64LABEL`.

**Architecture:** `tools/bas2seq/scan.py` walks quotes, `REM`, and `DATA`. `tools/bas2seq/engine.py` loads a file, renames long labels, proposes one replacement per source line, and writes the SEQ. `tools/bas2seq/highlight.py` only colors text for the screen. `tools/bas2seq/app.py` is the Textual session. The C64 editor and the three tools are left unchanged.

**Tech Stack:** Python 3, Textual for the screen, a plain `python3 tools/test_bas2seq.py` script for the engine and the highlighter.

## Global Constraints

- The program lives in `tools/bas2seq/`. CMake does not build it. Run it as `python3 -m bas2seq` from `tools/` after `textual` is installed.
- An editor line is at most 79 characters. The CR (`0x0D`) at the end of every SEQ line, including the last, is extra. The SEQ file contains no LF.
- Stored bytes are ASCII 32 through 126. The source file is UTF-8.
- A numbered line is optional spaces, then digits, then a space or the end of the line. `10PRINT` is a code line. A number is from 0 through 63999.
- A legal label is a letter, then letters or digits, at most 11 characters. Matching keeps the source case. A name of 11 or under stays, so `labelSetup` stays `labelSetup`.
- A longer name loses one exact lowercase `label` prefix when the rest starts with a letter, fits in 11, and collides with no kept name and no other candidate. Otherwise the user types the name.
- Reason phrases, used exactly: `GO TO joined`, `GO SUB joined`, `spaces collapsed`, `comment removed`, `PRINT shortened`, `split at colons`, `comment wrapped`, `assignment split`.
- Blocking phrases, used exactly: `duplicate label`, `unknown label`, `unknown line`, `label character`, `line number`, `duplicate line`, `character`, `comment word`, `expression piece`, `line length`.
- Keywords used to recognize jumps and lowercase warnings are the array in `src/conv/token.c`, in that order. `GOTO` is before `GO`. `PRINT#` is before `PRINT`.
- Highlight names and colors are `basic_keywords` and `basic_colors` in `src/editor_state.c`. On screen, purple is magenta and blue is blue. A `?` outside quotes and `REM` is magenta.
- Tests call the engine and the highlighter. They do not open the screen, VICE, or the Ultimate.
- Spec: `docs/superpowers/specs/2026-11-08-bas-to-seq-design.md`.

```python
def is_letter(ch):
    return ("A" <= ch <= "Z") or ("a" <= ch <= "z")


def is_name_char(ch):
    return is_letter(ch) or ("0" <= ch <= "9")


def word_at(text, index, keyword):
    """Length of keyword at index, or 0. A letter on either side rejects it."""
    size = len(keyword)
    if index > 0 and is_letter(text[index - 1]):
        return 0
    if index + size > len(text) or text[index:index + size] != keyword:
        return 0
    end = index + size
    if end < len(text) and is_letter(text[end]):
        return 0
    return size


def mask(text):
    """One region name per character: code, quote, rem, or data."""
    regions = []
    quote = False
    rem = False
    data = False
    i = 0
    while i < len(text):
        if rem:
            regions.append("rem")
            i += 1
            continue
        if quote:
            regions.append("quote")
            if text[i] == '"':
                quote = False
            i += 1
            continue
        if text[i] == '"':
            regions.append("quote")
            quote = True
            i += 1
            continue
        if data:
            if text[i] == ":":
                data = False
                regions.append("code")
            else:
                regions.append("data")
            i += 1
            continue
        if word_at(text, i, "REM"):
            regions.append("code")
            rem = True
            i += 1
            continue
        if word_at(text, i, "DATA"):
            regions.append("code")
            data = True
            i += 1
            continue
        regions.append("code")
        i += 1
    return regions
```

```python
from pathlib import Path

EXPLAIN = {
    "duplicate label": "This label name is already used. Rename one of them in the .bas file.",
    "unknown label": "This jump names a label the file does not define. Add the label or correct the name.",
    "unknown line": "This jump uses a line number the file does not contain.",
    "label character": "W64LABEL only takes letters and digits in a label. Remove the other character.",
    "line number": "A line number must be from 0 through 63999.",
    "duplicate line": "Two lines use this number. BASIC keeps one line per number.",
    "character": "The editor keeps characters from space through tilde. Replace this character in the .bas file.",
    "comment word": "A word in this comment is longer than a REM line. Break the word in the .bas file.",
    "expression piece": "One piece between + signs is longer than 79 characters. Shorten that piece in the .bas file.",
    "line length": "This statement is longer than 79 characters and has no colon or + to split on. Shorten it in the .bas file.",
}


class Block:
    def __init__(self, line_no, phrase, detail, original, replacement=None):
        self.line_no = line_no
        self.phrase = phrase
        self.detail = detail
        self.original = original
        self.replacement = replacement


class Session:
    def __init__(self):
        self.error = None
        self.source = []
        self.pending = []
        self.auto = {}
        self.given = {}
        self.items = []
        self.renames = []
        self.uses = {}


class Outcome:
    def __init__(self):
        self.unresolved = []
        self.warnings = []
        self.lines = None


def split_lines(text):
    if text == "":
        return []
    lines = []
    buf = []
    i = 0
    while i < len(text):
        ch = text[i]
        if ch == "\r":
            lines.append("".join(buf))
            buf = []
            i += 2 if i + 1 < len(text) and text[i + 1] == "\n" else 1
            continue
        if ch == "\n":
            lines.append("".join(buf))
            buf = []
            i += 1
            continue
        buf.append(ch)
        i += 1
    if buf:
        lines.append("".join(buf))
    return lines


def line_number(text):
    """None when the line is not numbered. ('bad',) when the number exceeds 63999.
    ('ok', value) otherwise."""
    i = 0
    while i < len(text) and text[i] == " ":
        i += 1
    if i >= len(text) or not text[i].isdigit():
        return None
    value = 0
    over = False
    while i < len(text) and text[i].isdigit():
        digit = ord(text[i]) - ord("0")
        if not over:
            if value > 63999 // 10 or (value == 63999 // 10 and digit > 63999 % 10):
                over = True
            else:
                value = value * 10 + digit
        i += 1
    if i < len(text) and text[i] != " ":
        return None
    if over:
        return ("bad",)
    return ("ok", value)


def _character_block(line_no, text):
    for ch in text:
        if ord(ch) < 32 or ord(ch) > 126:
            return Block(line_no, "character", EXPLAIN["character"], text)
    return None


def load(text):
    session = Session()
    session.source = split_lines(text)
    seen = {}
    for line_no, line in enumerate(session.source, 1):
        block = _character_block(line_no, line)
        if block:
            session.items.append(block)
            continue
        numbered = line_number(line)
        if numbered is None:
            continue
        if numbered[0] == "bad":
            session.items.append(Block(line_no, "line number", EXPLAIN["line number"], line))
            continue
        value = numbered[1]
        if value in seen:
            session.items.append(Block(line_no, "duplicate line", EXPLAIN["duplicate line"], line))
        else:
            seen[value] = line_no
    return session


def load_path(path):
    session = Session()
    try:
        raw = Path(path).read_bytes()
    except OSError as err:
        session.error = str(err)
        return session
    try:
        text = raw.decode("utf-8")
    except UnicodeDecodeError:
        session.error = "not UTF-8"
        return session
    return load(text)
```

```python
from bas2seq.scan import is_letter, is_name_char


def take_label(text):
    """Return the label name when the line starts with a legal or too-long label.
    None when the line does not start with name characters and a colon."""
    i = 0
    while i < len(text) and text[i] == " ":
        i += 1
    if i >= len(text) or not is_letter(text[i]):
        return None
    start = i
    while i < len(text) and is_name_char(text[i]):
        i += 1
    if i >= len(text) or text[i] != ":":
        return None
    return text[start:i]


def illegal_label(text):
    """True when a leading token reaches a colon through a character a label cannot hold."""
    i = 0
    while i < len(text) and text[i] == " ":
        i += 1
    if i >= len(text) or not is_letter(text[i]):
        return False
    saw_bad = False
    while i < len(text) and text[i] not in " :\"":
        if not is_name_char(text[i]):
            saw_bad = True
        i += 1
    return saw_bad and i < len(text) and text[i] == ":"


def _plan_renames(names):
    """names is first-seen order, duplicates already removed. Returns (auto, pending)."""
    occupied = {name for name in names if len(name) <= 11}
    auto = {}
    pending = []
    groups = {}
    order = []
    for name in names:
        if len(name) <= 11:
            continue
        candidate = None
        if name.startswith("label") and len(name) > 5 and is_letter(name[5]):
            rest = name[5:]
            if 1 <= len(rest) <= 11 and all(is_name_char(ch) for ch in rest):
                candidate = rest
        if candidate is None:
            pending.append(name)
            continue
        if candidate not in groups:
            order.append(candidate)
        groups.setdefault(candidate, []).append(name)
    for candidate in order:
        olds = groups[candidate]
        if len(olds) > 1 or candidate in occupied:
            pending.extend(olds)
        else:
            auto[olds[0]] = candidate
            occupied.add(candidate)
    return auto, pending


def mapping(session):
    names = dict(session.auto)
    names.update(session.given)
    return names


def supply(session, old, new):
    if old not in session.pending:
        return "unknown name"
    if new == "":
        return "empty"
    if not new or not is_letter(new[0]) or any(not is_name_char(ch) for ch in new):
        return "label character"
    if len(new) > 11:
        return "too long"
    taken = {name for name in session.auto.values()}
    taken.update(session.given.values())
    taken.update(name for name in _defined_names(session.source) if len(name) <= 11)
    if new in taken:
        return "already used"
    session.given[old] = new
    session.pending.remove(old)
    session.ready = False
    if old not in dict(session.renames):
        session.renames.append((old, new))
    session.renames = [(src, mapping(session)[src]) for src, _dst in session.renames]
    return None


def _defined_names(source):
    found = []
    seen = set()
    for line in source:
        if _character_block(0, line):
            continue
        name = take_label(line)
        if name and name not in seen:
            seen.add(name)
            found.append(name)
    return found
```

```python
from bas2seq.scan import mask, word_at


def _join_go(text):
    regions = mask(text)
    out = []
    notes = []
    i = 0
    while i < len(text):
        if regions[i] != "code":
            out.append(text[i])
            i += 1
            continue
        matched = _go_phrase(text, i)
        if matched:
            size, repl, note = matched
            out.append(repl)
            if note not in notes:
                notes.append(note)
            i += size
            continue
        out.append(text[i])
        i += 1
    return "".join(out), notes


def _go_phrase(text, index):
    if index > 0 and is_letter(text[index - 1]):
        return None
    if not text.startswith("GO", index):
        return None
    if index + 2 < len(text) and is_letter(text[index + 2]):
        return None
    j = index + 2
    if j >= len(text) or text[j] != " ":
        return None
    while j < len(text) and text[j] == " ":
        j += 1
    for second, repl, note in (("TO", "GOTO", "GO TO joined"), ("SUB", "GOSUB", "GO SUB joined")):
        if text.startswith(second, j):
            end = j + len(second)
            if end < len(text) and is_letter(text[end]):
                continue
            return end - index, repl, note
    return None


def _collapse(text):
    regions = mask(text)
    out = []
    for i, ch in enumerate(text):
        if ch == " " and regions[i] == "code" and out and out[-1] == " ":
            continue
        out.append(ch)
    return "".join(out)


def _drop_comment(text):
    regions = mask(text)
    rem_at = None
    for i in range(len(text)):
        if regions[i] == "code" and word_at(text, i, "REM"):
            rem_at = i
            break
    if rem_at is None:
        return None
    head = text[:rem_at].rstrip(" ")
    if head == "":
        return None
    if head.endswith(":"):
        head = head[:-1].rstrip(" ")
    if len(head) <= 79:
        return head
    return None


def _shorten_print(text):
    regions = mask(text)
    out = []
    changed = False
    i = 0
    while i < len(text):
        if regions[i] == "code" and word_at(text, i, "PRINT"):
            nxt = i + 5
            if nxt < len(text) and text[nxt] == "#":
                out.append(text[i])
                i += 1
                continue
            out.append("?")
            changed = True
            i += 5
            continue
        out.append(text[i])
        i += 1
    return "".join(out), changed


def _propose_early(text):
    """Return (lines, reason) when join, collapse, comment drop, or PRINT makes the line fit.
    Return None when the line still needs a later step. Return ('same',) when nothing changes."""
    joined, notes = _join_go(text)
    if len(joined) <= 79:
        if notes:
            return [joined], ", ".join(notes)
        return ("same",)
    work = joined
    if _collapse(work) != work:
        work = _collapse(work)
        notes.append("spaces collapsed")
    if len(work) <= 79:
        return [work], ", ".join(notes)
    dropped = _drop_comment(work)
    if dropped is not None:
        notes.append("comment removed")
        return [dropped], ", ".join(notes)
    shortened, changed = _shorten_print(work)
    if changed:
        notes.append("PRINT shortened")
        work = shortened
    if len(work) <= 79:
        return [work], ", ".join(notes)
    return None

    if session.pending:
        return
    # Length proposals are added in Task 4's prepare. This task fills items for
    # lines that the early ladder finishes. Task 4 replaces prepare with the full walk.

    for line_no, line in enumerate(session.source, 1):
        if any(item.line_no == line_no and item.replacement is None for item in session.items):
            continue
        result = _propose_early(_apply_ready(session, line))
        if result is None or result == ("same",):
            continue
        lines, reason = result
        if lines == [line]:
            continue
        if (line_no, reason) in existing:
            continue
        session.items.append(Block(line_no, reason, reason, line, lines))
```

```python
def _wrap_rem(piece):
    regions = mask(piece)
    start = 0
    while start < len(piece) and piece[start] == " ":
        start += 1
    if not word_at(piece, start, "REM"):
        return None
    body = piece[start + 3:]
    if body.startswith(" "):

            lines.append("REM" if body == "" else "REM " + body)

            i += 1

            if used + extra > budget:
                break

                return None

            used += extra
```

```python
        while index < len(line) and line[index] == " ":
            out.append(line[index])
            index += 1

            return index, None, set()
        used = set()

            out.append(line[index])

def resolve(session, accepted, accept_map):
    if not session.ready:
        prepare(session)
    outcome = Outcome()
    blocked = False
    for item in session.items:
        if item.replacement is None:
            outcome.unresolved.append(f"{item.line_no}: {item.phrase}")
            blocked = True
            continue
        if not accepted.get(item.line_no, False):
            outcome.unresolved.append(f"{item.line_no}: {item.phrase}")
            blocked = True
    if session.renames and not accept_map:
        blocked = True
    if blocked:
        return outcome
    built = []
    proposals = {item.line_no: item for item in session.items if item.replacement}
    for line_no, line in enumerate(session.source, 1):
        if line_no in proposals:
            built.extend(proposals[line_no].replacement)
            continue
        text, _err, _used = _rewrite_line(session, line)
        built.append(line if text is None else text)
    outcome.lines = built
    outcome.warnings = _warnings(built)
    return outcome


def write_seq(lines, path):
    data = b"".join(line.encode("ascii") + b"\r" for line in lines)
    Path(path).write_bytes(data)
```

- [ ] **Step 3: Write the session screens**

`app.main` constructs a Textual `App` whose state is the current `Session`, the accepted dict, the output path, and the last `Outcome`.

Screens, in order:

1. File screen. A `DirectoryTree` starts at the current working directory. Choosing a path that does not end in `.bas` leaves the tree up. Choosing a `.bas` file calls `load_path`. A session `error` is shown on this screen (`not UTF-8` or the OS message). Escape on this screen exits the app.
2. Save screen. The name starts as the source stem plus `.seq`, in the source file's directory. The user can change the directory and the name. If the path exists, Y replaces it and N returns to this screen. Escape returns to the file screen.
3. Name screen, one pending old name at a time. Enter calls `supply`. An error string stays on the screen under the field. Escape returns to the file screen.
4. Line screen. Walk `session.items` in order. Show the source line number, the original line through `spans`, and `detail`. A proposal also shows each replacement line through `spans`. Y stores `accepted[line_no] = True`. N stores `False`. A `replacement is None` item shows `phrase` and `detail` (`detail` is already `EXPLAIN[phrase]`), and Enter moves on. The walk continues after N. Escape returns to the file screen.
5. When any item is blocking or was answered N, show those `line_no` and `phrase` values, then a key returns to the file screen. `write_seq` is not called.
6. When `renames` is non-empty, show each old name, the new name from `mapping`, and each source line in `uses`, colored with `spans`. Y continues. N returns to the file screen.
7. Warning screen. `resolve(session, accepted, True)` has already produced `warnings`. The list scrolls. W calls `write_seq(outcome.lines, path)`. Escape returns to the file screen and does not write. If `write_seq` raises `OSError` or `UnicodeEncodeError`, show `str(err)` and return to the save screen with the outcome kept.
8. Done screen. Show the path, `len(outcome.lines)`, and `len(outcome.warnings)`. A key returns to the file screen.

A file with no pending names skips step 3. A file with no items skips step 4. A file with no renames skips step 6. The warning screen still appears.

`spans` becomes a Rich `Text`: `statement` is `magenta`, `function` is `blue`, `plain` is the default.
